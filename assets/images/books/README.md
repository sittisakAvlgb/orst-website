# Book covers

The homepage books row ("หนังสือและ E-Book") looks here for a cover photo for each book. Drop the file in
and rebuild — nothing else to edit. Until a file exists, a two-tone cover with the book's title
stands in.

`webp` is tried first, then `jpg`, `jpeg`, `png`, `avif`. The build lists what it found under **Book covers**.

## What the cover needs to be

- **Portrait, about 3 : 4** (for example 600 × 800 px). The image fills the book face, cropped to fit.
- **Under 250 KB.**
- **The real cover of the published book**, supplied or approved by the Office — never a mock-up.
