## ขนาดที่แนะนำ

- **ไฟล์หลัก:** 1920 × 600 px ดีที่สุด — รูปขนาดอื่นใช้ได้ แต่จะถูก **ครอปอัตโนมัติ** ให้ทุกสไลด์สูงเท่ากัน
  (จอกว้างครอปเป็นสัดส่วน 1920:600, มือถือครอปเป็น 16:9 โดยยึดกลางภาพค่อนล่าง)
  จึงควรวางคน ตัวหนังสือ หรือจุดสำคัญไว้ช่วงกลางภาพ อย่าชิดขอบบนหรือล่าง
- **ไฟล์มือถือ:** เช่น 1080 × 608 px (16:9) — แสดงบนจอกว้างไม่เกิน 767 px ถ้าไม่ใส่ มือถือจะใช้ไฟล์หลักแทน
  ควรทำไฟล์มือถือถ้าแบนเนอร์มีตัวหนังสือในรูป
- **ขนาดไฟล์:** ไม่เกินประมาณ 600 KB ต่อรูป (บีบอัด PNG ด้วย TinyPNG หรือ Squoosh ก่อนใส่)
- เว้นมุมขวาล่างประมาณ 560 × 96 px ไว้ เพราะมีกล่อง "ระบบบริการอิเล็กทรอนิกส์ / ข้อสอบถาม" วางทับ
  และแถบล่างสูง 40 px (ชื่อหน่วยงานและจุดเลื่อนสไลด์)

## เปลี่ยนข้อความ ลิงก์ หรือจำนวนสไลด์

แก้ที่ `src/banners.json`

- `alt` — **ต้องแก้ให้ตรงกับข้อความในรูป** ทั้งภาษาไทยและอังกฤษ (ผู้ใช้โปรแกรมอ่านหน้าจอได้ยินข้อความนี้)
- `title` — ชื่อสั้นของสไลด์ ใช้กับปุ่มจุดเลื่อนสไลด์
- `page` (รหัสหน้าในเว็บ เช่น `news`) หรือ `href` (ลิงก์ เช่น `#knowledge-search` หรือ URL ภายนอก)
- `caption` — ข้อความแถบล่าง ถ้าไม่ใส่จะใช้ `defaultCaption`
- เพิ่มหรือลบรายการใน `slides` ได้ จุดเลื่อนสไลด์จะปรับตามจำนวนเอง

หลัง build ระบบจะรายงาน เช่น `Banners: 3/5 images in place.` พร้อมเตือนถ้าขนาดรูปไม่ตรงหรือไฟล์ใหญ่เกินไป
